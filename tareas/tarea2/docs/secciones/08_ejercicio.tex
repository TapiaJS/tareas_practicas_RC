\section{Problema 8: Conexión entre computadoras}

\begin{tcolorbox}[enunciado]
PC-A quiere comunicarse con 192.168.1.20, pero solamente conoce la dirección IP. (Observe la imagen del anterior problema). Explica qué ocurre antes de que PC-A pueda enviar correctamente una trama Ethernet al destino.

Indica:
\begin{itemize}[leftmargin=*]
    \item ¿Qué protocolo interviene?
    \item ¿Qué dirección conoce inicialmente PC-A?
    \item ¿Qué dirección necesita conocer?
    \item ¿Qué información viaja en la solicitud?
    \item ¿Qué información obtiene en la respuesta?
\end{itemize}
\textbf{Hint:} Una dirección pertenece a Capa 3 y otra a Capa 2. ¿Cómo puede una máquina pasar de una a otra?
\end{tcolorbox}

\subsection*{Solución}

\begin{enumerate}[label=\arabic*., leftmargin=*]
    \item ¿Qué protocolo interviene?\\\\
    El protocolo ARP (Address Resolution Protocol).
    \item ¿Qué dirección conoce inicialmente PC-A?\\\\
    Conoce únicamente la dirección IP de destino: 192.168.1.20 (la cual es una dirección lógica de Capa 3).
    \item ¿Qué dirección necesita conocer?\\\\
    Necesita conocer la dirección MAC de destino (la cual es una dirección física de Capa 2) para poder armar la trama Ethernet.
    \item ¿Qué información viaja en la solicitud?\\\\
    Viaja un mensaje ARP Request en formato de Broadcast (dirigido a la MAC FF:FF:FF:FF:FF:FF). 
    Este mensaje inunda la red local preguntando: ¿Quién tiene la IP 192.168.1.20?.
    \item ¿Qué información obtiene en la respuesta?\\\\
    Obtiene un mensaje ARP Reply directamente desde PC-B (Unicast) informando su dirección MAC exacta (0002.4A91.DC6E).
\end{enumerate}
