\subsection*{Solución}
\subsubsection*{Lista de Redes}
Se ordena de mayor a menor las redes de acuerdo a los hosts que necesitan y se le suman 2 hosts extra (segmento de red y el segmento broadcast):

\begin{itemize}[leftmargin=*]
    \item \textbf{Tlahuizcalpan:} $5354 + 2 = 5356$ hosts
    \item \textbf{Poniente:} $2700 + 2 = 2702$ hosts
    \item \textbf{Oriente:} $2480 + 2 = 2482$ hosts
    \item \textbf{Amoxcalli:} $2392 + 2 = 2394$ hosts
    \item \textbf{Física:} $2382 + 2 = 2384$ hosts

    \item \textbf{Matemáticas:} $266 + 2 = 268$ hosts
